# Solana.new artwork

The SVG files were extracted from the supplied Figma frame `3338:2` (1920 by 4927) on 2026-09-08. `figma-page.svg` preserves the full export for reference. The page loads the smaller individual pieces so text can reflow and the cards can stack on narrow screens.

The logo's blur was removed, card illustrations retain the CSS export's `screen` blend mode, and the approved sentence punctuation is preserved. Display lettering and ornaments are original vector outlines. Card WebP files are web-sized exports of the embedded source illustrations.

Body typography uses Redaction, with Redaction 50 for the final link, from the official package at https://www.redaction.us/static/redaction.zip. The font license is included in `fonts/OFL.txt`.
